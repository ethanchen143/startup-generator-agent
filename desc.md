# Autonomous Idea & Prototype Generator Agent System (5-Day Agent)

An autonomous, multi-agent pipeline built with **Google Agent Developer Kit (ADK) in Python** and a **TypeScript frontend dashboard**. The system runs every top of the hour to discover industry opportunities, perform deep market research, generate startup product concepts, and build working mock React applications for entrepreneurs.

---

## 🤖 System Architecture & Sequential Agent Workflow

The backend system is orchestrated as a sequential pipeline running every top of the hour (with Start / Stop controls in the UI):

1. **Discovery Agent**:
   - **Tool**: Google Search API.
   - **Function**: Scans random business verticals / industries to uncover emerging pain points, underserved niches, and market opportunities.
   - **Output**: Structured `DiscoveryResult`.

2. **Market Research Agent**:
   - **Tool**: Google Search API.
   - **Function**: Takes the discovered problem/vertical and conducts deep market analysis (competitors, target demographics, market size, existing solutions).
   - **Output**: Structured `MarketResearchReport`.

3. **Ideation Agent**:
   - **Function**: Synthesizes market research findings into a concrete product concept, defining key features, unique value proposition, and user experience requirements.
   - **Output**: Structured `ProductSpec`.

4. **Implementation Agent**:
   - **Tool**: Custom WebDev File Writer Tool.
   - **Function**: Autonomously writes source code for a complete mock **React application** fulfilling the `ProductSpec`, saving project files into a dedicated local workspace directory (`/generated-apps/<project-id>/`).
   - **Output**: `AppBuildArtifact` containing file manifests and preview paths.

---

## 🎨 Tool & Interface Design (TypeScript UI)

- **Entrepreneur Dashboard**: A modern TypeScript dashboard allowing users to start/stop the hourly automated pipeline and browse generated startup packages.
- **Startup Card Feed**: Each generated idea displays:
  - Industry & Problem Statement
  - Market Size & Competitor Analysis
  - Product Concept & Feature List
  - Embedded Live Preview / Iframe rendering the generated React app prototype.
- **Source Code Access**: Direct access to local React project directories generated by the Implementation Agent.

---

## 🧠 Context & Memory (ADK Session State)

- **Inter-Agent Context Flow**: Typed JSON schemas passed sequentially down the pipeline (`DiscoveryResult` → `MarketResearchReport` → `ProductSpec` → `AppBuildArtifact`).
- **Session & Memory Management**: Leverages Google ADK / Vertex AI Agent Engine native state and session management for persistence and context retention (no separate external DB).

---

## ⚙️ Orchestration & Logic

- **Scheduler**: Top-of-the-hour Cron scheduler managed in the backend service.
- **UI Controls**: Simple Start / Stop control panel in the TypeScript UI to pause or resume execution.
- **Minimal Workflow**: Lightweight, deterministic execution pipeline focused on end-to-end flow without unnecessary fix-loops or heavy error checking.

---

## 📊 Observability & Tracing

- **Real-Time Agent Trace Feed**: The TypeScript UI streams agent thought processes, active search queries, tool executions (file creation), and pipeline step status in real-time.
- **Telemetry**: Integrates ADK observability features for step-by-step tracing and performance visibility.
